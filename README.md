# ![UChat Logo](app/static/images/logo.svg) UChat | Custom Twitch & Kick Chat Overlay

[![Crowdin](https://badges.crowdin.net/uchat-app/localized.svg)](https://crowdin.com/project/uchat-app)

Project is currently deployed at: https://chat.unii.dev/

A highly customizable Twitch & Kick chat overlay for OBS and other streaming programs.

> [!WARNING]
> The readme isn't frequently updated, make sure to check the deployment over at https://chat.unii.dev/

## Want your app’s badges or your bot added to the overlay?

Create a pull request.

## Chat Customization Settings

- Messages in **bold**
- Messages in UPPERCASE
- Smooth message scroll
- Custom chat font
- Chat font color
- Font & badge size
- Font stroke
- Message shadow
- Emote size
- Text fade out
- Display badges
- Display channel points, subs, announcements
- Hide bot messages
- Custom user blacklist
- Custom prefix blacklist
- Moderation action effect
- Mentions colored
- Display 7TV Paints
- Display 7TV Paint Shadows
